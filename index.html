Linux systems · Machine learning

MemoryMedic

I built a C++17 monitor that reads memory usage, thread counts, and page faults from Linux processes. With MemoryMedic AI 2.0, I added a dashboard where developers can select a recorded run, inspect its memory trend, and request a leak prediction.

I tested the classifier on four synthetic workloads: steady memory use, a linear leak, temporary spikes, and cache growth. It correctly classified all 156 measurements from four runs held out for testing.
